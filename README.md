# FormularioJS
Recriação do Site da Etec Da Zona Leste, com CSS, JS, HTML e PHP, com formulário que da avisos ao usuário com quantidade de caracteres e para selecionar um curso

<img width="1359" height="754" alt="image" src="https://github.com/user-attachments/assets/d292b3ef-4487-41d6-bcdb-295ebce672e2" />
Ao tentar escrever nome e mensagem com uma quantidade muito pequena de caraceres, o JS impede o envio e manda um viso ao usuario informando os valores mínimos para cada área. Caso o usuário tente mandar sem escolher um curso, ele também recebe um aviso sobre isso.
